# Sazón-de-Barrio-Restaurante-Criollo-Peruano-Pagina-Web

Sazón de Barrio es un proyecto de desarrollo web que presenta una plataforma interactiva para un restaurante especializado en gastronomía criolla peruana. Su objetivo es ofrecer a los usuarios una experiencia moderna, intuitiva y accesible para explorar platos tradicionales, consultar promociones, realizar solicitudes de pedidos y gestionar solicitudes de reservas.

Este proyecto fue desarrollado con fines académicos, aplicando conocimientos de diseño web, programación e interacción con el usuario.

- Tecnologías utilizadas

El proyecto fue desarrollado utilizando tecnologías fundamentales del desarrollo web:

HTML5: estructura y organización del contenido.

CSS3: diseño visual, estilos, animaciones y adaptación a diferentes tamaños de pantalla.

JavaScript (Vanilla JS): funcionalidades interactivas, manipulación del DOM y lógica de la aplicación.

LocalStorage: almacenamiento local de los productos seleccionados en el carrito.

Google Fonts: tipografías utilizadas para mejorar la presentación visual.

Funcionalidades principales

1. Página de inicio

Presentación del restaurante con una interfaz visual inspirada en la gastronomía y cultura peruana.

2. Carta gastronómica interactiva

Catálogo de platos tradicionales, bebidas y postres, con imágenes, descripciones y precios.

3. Promociones

Sección dedicada a presentar combinaciones y ofertas gastronómicas.

4. Carrito de compras

Permite agregar productos, modificar cantidades, calcular importes y conservar la selección mediante LocalStorage.

5. Solicitudes de pedidos por WhatsApp

Generación de mensajes con los productos seleccionados y la modalidad del pedido (delivery o recojo).

6. Solicitudes de reservas

Formulario interactivo para ingresar datos personales, fecha, hora y cantidad de comensales. La solicitud se prepara para enviarse por WhatsApp y queda sujeta a confirmación.

- Objetivo académico

Demostrar la aplicación práctica de los conocimientos adquiridos en desarrollo web mediante la creación de una página funcional, organizada e interactiva, integrando estructura, diseño, programación y principios básicos de experiencia de usuario.

- Cómo ejecutar el proyecto

Descargar el archivo ZIP.

Extraer los archivos.

Abrir la carpeta en VsCode.

Es necesario contar con la extension "Live Preview", para poder visualizar la pagina correctamente con todos sus elementos y funciones.
